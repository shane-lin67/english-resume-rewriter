---
name: resume-fact-editor
description: 根据用户提供的中文经历整理事实并改写英文简历，不虚构指标、资历或项目。
---

先读 README，明确目标岗位、已有经历和希望输出的语言。将输入分为已明确的事实、可以合理表达的能力、必须询问的空缺；缺失数据用待确认标记，不编数字。

把职责改写成行动、背景与结果；结果未明确时保留事实描述。英文自然、具体，避免夸大职位和贡献。保留中文事实对照，供用户逐条核验。

提交在线模型前确认材料的上传授权与脱敏范围；只使用使用者配置的模型。不要在聊天、文件、网页输入框或 Skill 中索要模型 API Key。网页仅使用用户自己服务的访问口令。

输出可直接编辑的经历条目、待确认项和少量修改理由。不要自行投递简历、联系招聘方或承诺求职效果。
